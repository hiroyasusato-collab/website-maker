# 参考リンクの設定
#
# ここに書いたリンクが、ページの「参考リンク」の欄に上から順に並びます。
#
# ・1行に1つ。書き方は次のとおりです
#
#       表示名 | URL
#
#   「|」は半角の縦棒です。全角の「｜」でもかまいません。
#   URL だけを書いた場合は、URL がそのまま表示名になります。
#
# ・行頭に # を付けるとその行は無視されます
# ・1行も書かなければ、ページから「参考リンク」の欄ごと出なくなります
# ・編集したらファイルを保存するだけです。プログラムを直す必要はありません
#
# 【このファイルのリンクは取得しません】
# ほかの設定ファイル（keywords.txt など）と違い、ここに書いた先には
# プログラムから一切アクセスしません。ページにリンクを置くだけです。
# 利用規約でプログラムからの収集が禁止されているサイトを、
# 手で開けるようにしておくための欄です。
#
# 【URL の決まり】
# http:// または https:// で始まるものだけを受け付けます。
# それ以外の行は読み飛ばし、実行したときの画面にお知らせが出ます。

Speaker Deck（「AI」の検索結果） | https://speakerdeck.com/search?q=AI
