# キーワード別セクションを「ページに出す順番」の設定
#
# ・1行に1つの表の名前。ここに書いた順にページへ並びます
# ・2列で表示されるので、上から「左・右・左・右…」の順に入ります
#     1行目 → 左列、2行目 → 右列
#     3行目 → 左列、4行目 → 右列  …
# ・行頭に # を付けるとその行は無視されます
# ・編集したらファイルを保存するだけです。プログラムを直す必要はありません
#
# 【表を置かない位置を作りたいとき】
# 「（空き）」と書いた行は、表を置かない場所になります。
# 右列を空けて、次の表を左列から始めたいときに使います。
# 「(空き)」「空き」「-」と書いても同じ意味になります。
#
# 【keywords.txt との違い】
# keywords.txt … 同じ記事が複数の表に当てはまったとき、どちらに載せるかの優先順
# このファイル  … ページに出す順番（見やすさのため）
# 2つは別物です。このファイルを並べ替えても、どの記事がどの表に載るかは変わりません。
#
# 【表の名前の書き方】
# keywords.txt で1行にカンマ区切りで複数の単語を書いた表は、
# 単語を「・」でつないだ名前になります（例：RAG・ナレッジグラフ）。
# このファイルにはその名前を書いてください（カンマ区切りで書いても通じます）。
#
# 【書かなかった表の扱い】
# keywords.txt にあってこのファイルに無い表は、ページの末尾に追加されます。
# キーワードを増やしたときに、ここへ書き忘れても消えることはありません。
#
# ※ AI業界トレンド（はてなブックマーク・Hacker News・X）と
#   技術資料・リポジトリ（GitHub・技術評論社）の並びは固定で、このファイルの対象外です。
