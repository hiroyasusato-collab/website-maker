# キーワード別セクションを「ページに出す順番」の設定
#
# ・1行に1キーワード。ここに書いた順にページへ並びます
# ・2列で表示されるので、上から「左・右・左・右…」の順に入ります
#     1行目 → 左列、2行目 → 右列
#     3行目 → 左列、4行目 → 右列  …
# ・行頭に # を付けるとその行は無視されます
# ・編集したらファイルを保存するだけです。プログラムを直す必要はありません
#
# 【keywords.txt との違い】
# keywords.txt … 同じ記事が複数のセクションに該当したとき、どちらに載せるかの優先順
# このファイル  … ページに出す順番（見やすさのため）
# 2つは別物です。このファイルを並べ替えても、どの記事がどのセクションに載るかは変わりません。
#
# 【書かなかったキーワードの扱い】
# keywords.txt にあってこのファイルに無いキーワードは、ページの末尾に追加されます。
# キーワードを増やしたときに、ここへ書き忘れても消えることはありません。
#
