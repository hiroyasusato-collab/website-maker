# キーワード別セクションの設定
#
# ・1行に1つの表
# ・ここに書いた順番が「同じ記事が複数の表に当てはまったとき、どちらに載せるか」の
#   優先順になります（先に書いたほうが優先）
# ・ページに出す順番は display_order.txt で別に指定します
# ・行頭に # を付けるとその行は無視されます（一時的に外したいとき便利）
# ・編集したらファイルを保存するだけです。プログラムを直す必要はありません
#
# 【1つの表に複数の単語をまとめたいとき】
# 1行にカンマ（,）で区切って並べると、どれかに当たる記事が1つの表に入ります。
#   例： RAG, ナレッジグラフ
#        → 「RAG・ナレッジグラフ」という名前の表になり、
#          RAG を含む記事とナレッジグラフを含む記事の両方が並びます
# 表の名前は、書いた単語を「・」でつないだものになります。
# display_order.txt にはこの名前（RAG・ナレッジグラフ）を書いてください。
# 単語を増やすとその分だけ取得の回数と実行時間が増えます。
#
# 【短い英語のキーワードについて】
# 3文字くらいの英語は、別の意味の英単語と衝突することがあります。
# 例：「RAG」は布・ぼろ布という意味の英単語 rag とも一致するため、
#     古着リサイクルの記事（Rag House TV など）が混ざります。
# 気になる場合は「RAG 検索」のように語を足すか、この行を # で外してください。
